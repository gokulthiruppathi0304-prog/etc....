# SKILLPATH AI 2.0
> **Tagline:** Discover your potential. Bridge your skill gaps. Engineer your future.

SkillPath AI 2.0 is an intelligent career evolution platform designed for students and aspiring developers. Powered by a coordinated **8-agent Python AI mesh** with a central orchestrator and a modern dark navy SaaS dashboard, SkillPath AI analyzes competencies, diagnoses skill gaps, matches career pathways, generates adaptive weekly roadmaps, and provides verified evidence-backed assessments.

## Quick Start
```bash
# Backend (Port 8000)
cd backend
source venv/bin/activate
PYTHONPATH=. uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

# Frontend (Port 5173)
cd frontend
npm run dev
```
